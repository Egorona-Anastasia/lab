# Описание лабораторной: 
Обработка изображений с использованием многопоточности

Этот код реализует многопоточную обработку изображений с использованием блокирующих очередей для передачи данных между потоками.

## Используемые технологии

- Python 3.x
- Библиотека Pillow для работы с изображениями
- Модуль `threading` для реализации многопоточности
- Модуль изображедля управления очередями данных
